## What this is

The safe way to read cart price rules: a rule's action and free-shipping setting, the rules a quote has applied, and the rule behind a coupon code. Batched, staging-aware and memoised, so the questions that are a column lookup stop costing a hydrated rule.

Say what problem that solves, in the reader's own terms, before any mechanics.

## Step 1: install it

```bash
composer require commerce/module-promotion-access
```
